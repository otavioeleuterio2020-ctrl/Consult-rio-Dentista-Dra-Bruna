# Consultório Dra. Bruna Amazonas Aloise

Site estático (HTML, CSS e JS). Para publicar: GitHub Pages em Settings → Pages → branch `main`, pasta `/ (root)`.

## Fotos reais
Coloque as fotos autorizadas em `img/` com estes nomes. Sem elas o site mostra uma ilustração (hero e consultório) e a galeria fica oculta; cada foto da galeria aparece sozinha assim que o arquivo existir:
- `img/hero.jpg` (retrato vertical, proporção ~4:5)
- `img/consultorio.jpg` (ambiente do consultório)
- `img/galeria-1.jpg` a `img/galeria-5.jpg` (galeria com ampliação ao clicar)

## Pendências a confirmar com a profissional
Logo oficial, registro no CRO, redes sociais, link oficial das avaliações e quais procedimentos são oferecidos.
